# Pocketto — Pocket-driven development skills

Pocketto provides 16 skills for structured software development, including subagent delegation, iterative planning, code review, and an opt-in enterprise workflow.

Gemini CLI automatically discovers skills bundled under the extension's `skills/` directory and activates them when relevant. The skills are not imported into this context file, so their full instructions remain available on demand.

This repository includes both Core and Enterprise skills. Installing the extension from the repository root makes all 16 discoverable; it is not a Core-only distribution.
